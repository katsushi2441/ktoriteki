# Kurage 取適法チェック（ktoriteki）

2026年1月1日施行の取適法（中小受託取引適正化法・旧 下請法）について、

1. その取引が対象になるか（取引の内容＋資本金・常時使用する従業員の規模要件）
2. 4つの義務と11の禁止行為のどこに気をつけるか（発注する側／受ける側）

を、質問に答えるだけで確かめる1ファイルの PHP です。判定はブラウザの中だけで行い、入力はサーバーへ送りません。

公開: https://kurage.exbridge.jp/ktoriteki.php/

出典: 公正取引委員会「委託事業者の義務」、公正取引委員会 中部事務所「中小受託取引適正化法（取適法）について」（令和8年3月9日）。法律の助言ではありません。

置き方: `php/ktoriteki.php` を PHP 8.1 以上のサーバーに置くだけ（DB不要）。`SITE` / `BASE` を自分の URL に変える。
